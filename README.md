# 関東・日当たりチェッカー

築古不動産（ボロリッチ／築福不動産）の配布特典。
住所と「目の前の建物の高さ・距離」を入れると、冬至にその窓へ何時間日が入るかを計算します。

- 公開URL: https://satokott4274-blip.github.io/bororich-hiatari/
- 単一HTML・依存ライブラリなし
- 太陽位置：NOAA の計算式を自前実装（東京の冬至 日の出06:47／日の入16:32／南中高度30.87° で検算済み）
- 住所検索：国土地理院 AddressSearch API（キー不要・CORS開放）
- 太陽高度5度以下の斜光は日照に数えない（周囲の家・塀・樹木に遮られるため）

更新は index.html を編集して push するだけ（GitHub Pages が自動反映・約1分）。
